# AdventurePeak 0.1.0

Initial release for Foundry VTT 13.351 and dnd5e 5.3.0.

## Installation

In Foundry Setup, open **Add-on Modules → Install Module** and paste this Manifest URL:

```text
https://github.com/eating1battery/fvtt-adventure-peak/releases/latest/download/module.json
```

Enable AdventurePeak in the world's **Manage Modules**, then enable **Rest Rules**, **Side Initiative**, or both in module settings. Both settings default to disabled and require a reload when changed.

## Included

- Two spell slots recovered per spent Hit Die, lowest level first, with a checked-by-default opt-out control. Normal healing is retained, including spending Hit Dice at full HP.
- Long rests preserve expended spell slots, restore Hit Dice using the 2014 half-total rule, and remind players to obtain DM permission without blocking them.
- Automatic recovery of up to two Pact Magic slots per short rest.
- Side initiative based on each side's precise average, with friendly ties, fixed encounter averages, and whole-number display.
- Friendly PC and hostile NPC defaults, individual/group assignment buttons, and a DM option to swap side order next round.
- A compact tracker layout with name, HP/resource, and initiative on one row and assignment controls below.

## Known limitations

- Song of Rest slot recovery and once-per-consecutive-rest tracking are not implemented yet.
- Independent combatant completion and automatic advancement after every side member finishes remain unfinished. This release groups turn order by side and uses Foundry's native individual turn controls.
- Hit Dice restore regular Spellcasting slots; Pact Magic uses its separate automatic recovery.
- Foundry v14 and dnd5e 6 support are deferred.

Existing sum-based encounters provide **Recalculate using averages** to establish an average-based snapshot from current combatants and rolls.
