# AdventurePeak 0.1.1

Long rests now restore spell slots normally through dnd5e, including Pact Magic slots. The module no longer removes the system's long-rest recovery updates.

Short rests retain two regular spell slots per Hit Die and automatic recovery of up to two Pact Magic slots. The DM-permission reminder and 2014 long-rest Hit Dice recovery remain unchanged.

Update through Foundry's module updater using the existing manifest URL:

```text
https://github.com/eating1battery/fvtt-adventure-peak/releases/latest/download/module.json
```

Targets Foundry 13.351 and dnd5e 5.3.0. All 30 automated tests pass. Song of Rest tracking and independent combatant completion remain unfinished, as noted in v0.1.0.
